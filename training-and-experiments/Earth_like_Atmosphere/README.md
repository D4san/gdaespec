# G-DAE for an Earth-like Atmosphere (TRAPPIST-1e Analog)

This directory contains the workflow used to train and evaluate the G-DAE on
Earth-like transmission spectra for a TRAPPIST-1e analog.

## Data Provenance

The base spectral dataset is derived from
[Duque-Castaño et al. (2025)](https://academic.oup.com/mnras/article/539/2/1528/8109635).
The original data and generation workflow are available in
[MultiREx-public](https://github.com/D4san/MultiREx-public/tree/main/examples/papers/DZF-MLBiosignatureClassification).

The PHOENIX- and SPHINX-based stellar-contamination curves used for TRAPPIST-1
are documented in
[`stellar_contamination/`](stellar_contamination/).

## Workflow

The experiment is organized in the following order:

1. `01_G-DAE.ipynb`
   assembles the training set and trains the G-DAE using the available
   stellar-contamination curves.
2. `02_G-DAE_Analysis.ipynb`
   evaluates the trained model through reconstruction metrics, uncertainty
   estimates, and diagnostic plots.
3. `Retrieval Tests/`
   evaluates the reconstructed spectra in a POSEIDON retrieval campaign.

## Main Files and Products

| Path | Purpose |
| --- | --- |
| `spec_data/` | Earth-like spectral datasets used to train and evaluate the G-DAE. |
| `stellar_contamination/` | PHOENIX- and SPHINX-based contamination curves for TRAPPIST-1. |
| `Models/` | Trained G-DAE model artifacts. |
| `plots/` | Selected figures generated by the analysis notebooks. |
| `Retrieval Tests/` | POSEIDON scripts and the preserved retrieval record. |
| `waves.txt` | Wavelength grid shared by the Earth-like workflow. |
| `pandexo_spec.txt` | PandExo spectrum used by the Earth-like analysis notebook. |

## Retrieval Validation

The retrieval experiment uses five PandExo noise realizations and compares two strategies:

- `gdae`: the observed spectrum is reconstructed with the G-DAE before
  POSEIDON retrieves the atmospheric parameters.
- `contam`: POSEIDON jointly retrieves the atmospheric and
  stellar-contamination parameters from the raw contaminated observation.

The complete procedure is documented in
[`Retrieval Tests/README.md`](Retrieval%20Tests/README.md). The observations,
logs, samples, MultiNest state, figures, and aggregate tables are preserved in
[`Retrieval Tests/campaign_5obs/`](Retrieval%20Tests/campaign_5obs/).
