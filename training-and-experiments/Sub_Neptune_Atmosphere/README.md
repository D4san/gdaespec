# G-DAE Training on Sub-Neptunes (K2-18b Analog)

This directory contains the synthetic sub-Neptune experiment used to train and
evaluate the G-DAE for a K2-18b analog. The spectral grid represents an
H2-He-dominated atmosphere with trace gases. The training workflow combines
these spectra with spot- and facula-driven stellar contamination and
JWST/NIRSpec Prism noise generated with PandExo.

## Workflow

The notebooks are organized in the following order:

1. `01_Spectra_Generation.ipynb`
   generates the synthetic transmission-spectra grid.
2. `02_Stellar_Contamination.ipynb`
   computes the wavelength-dependent stellar-contamination factor
   $\epsilon(\lambda)$ across the selected spot and facula configurations.
3. `03_AE_Training.ipynb`
   builds the training dataset and trains the G-DAE to reconstruct clean
   spectra from contaminated and noisy inputs.
4. `04_G-DAE_Evaluation.ipynb`
   evaluates the trained model through three experiments:
   1. uncertainty decomposition for a fixed transit count;
   2. sensitivity to transit count and stellar activity;
   3. a DMS N+1 out-of-distribution test.

## Main Files and Products

| Path | Purpose |
| --- | --- |
| `specs/` | Generated synthetic transmission-spectra datasets used for training and evaluation. |
| `TLS/` | Stellar-contamination curves used by the sub-Neptune workflow. |
| `plots/` | Selected figures generated by the analysis notebooks. |
| `AE.keras` | Trained G-DAE model used by the evaluation notebook. |
| `waves.txt` | Wavelength grid shared by the experiment. |

## Regenerating the Spectral Dataset

`01_Spectra_Generation.ipynb` automatically downloads missing CIA, PHOENIX,
and opacity inputs when the synthetic spectra are regenerated. These large
local inputs are excluded from Git.

The sub-Neptune analysis is separate from the Earth-like POSEIDON retrieval
campaign in [`../Earth_like_Atmosphere/`](../Earth_like_Atmosphere/).
